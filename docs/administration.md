# WRIT 관리자 가이드

## 관리자 접근

관리자(owner/admin/moderator)로 로그인한 뒤 `https://<서버주소>/admin` 에서 서버를 관리할 수 있습니다.

## 역할(Role)

역할은 `user < moderator < admin < owner` 순으로 권한이 높습니다.

| 역할 | 설명 |
|------|------|
| `owner` | 첫 번째 가입 계정. 최고 권한. |
| `admin` | 역할 변경, 서버 정보 수정 등 대부분의 관리 기능. |
| `moderator` | 유저 관리, 신고 처리, 콘텐츠/연합 관리 등 일상 중재 업무. |
| `user` | 일반 사용자. |

- 관리자가 자신과 **동급 이상**의 계정을 관리하려 하면 차단됩니다 (자기 자신, 상위 역할 계정 보호).
- 역할 변경(`owner` 포함)은 `admin`/`owner`만 할 수 있습니다.

## 관리 페이지

`/admin` 진입 시 대시보드에 사용자/게시글/시리즈 통계가 표시됩니다.

### 중재

| 메뉴 | 경로 | 기능 |
|------|------|------|
| 유저 관리 | `/admin/users` | 계정 검색·상세 확인. 비밀번호 초기화, 이메일 변경, 이메일 인증 처리, 역할 변경, 동결(freeze), 정지(suspend), 삭제 등. |
| 신고 관리 | `/admin/reports` | 사용자 신고 목록과 처리. |
| 연합 | `/admin/federation` | 연합 모드(블랙리스트/화이트리스트), 차단 도메인, 허용 서버, 원격 서버 목록 관리. |
| 도메인 차단 | `/admin/blocked-domains` | 가입 시 사용할 수 없는 **이메일 도메인** 차단. |
| 규칙 | `/admin/rules` | 서버 규칙 작성. 가입 화면에서 동의 항목으로 노출됩니다. |
| 중재 기록 | `/admin/moderation-log` | 관리자가 수행한 행동의 로그 (계정 생성, 로그인 실패, 정지, 삭제 등). |
| 콘텐츠 관리 | `/admin/content` | 게시글/댓글 검색·삭제 등 콘텐츠 중재. |
| 공지사항 | `/admin/announcements` | 서버 공지 등록·관리. |
| 원격 서버 | `/admin/remote-server/[도메인]` | 특정 원격 서버 상세 정보·관리. |

### 관리

| 메뉴 | 경로 | 기능 |
|------|------|------|
| 서버 정보 | `/admin/settings` | 서버 이름, 서버 설명, 대표 아이콘(로고), 파비콘, 모바일 앱 아이콘, 관리자 계정 표시, 관리 이메일, 이모지 반응 활성화 여부. |
| 커스텀 이모지 | `/admin/emojis` | 커스텀 이모지 업로드·관리. |

## 연합(Federation) 모드

- **블랙리스트(기본)** — 기본적으로 모든 서버와 연합하고, 차단한 도메인만 제외합니다.
- **화이트리스트** — 허용한 서버와만 연합합니다.

## 사용자별 글 자동 삭제

각 사용자는 설정(`/users/settings/auto-delete`)에서 본인 글의 자동 삭제 기간을 설정할 수 있습니다.

- 기간: 글 작성일 기준 N일이 지나면 자동 삭제 (하루 한 번 3시 워커가 처리).
- 예외 조건: 기간을 설정하지 않아도 **예외 항목 설정은 항상 표시**됩니다. 예외에 체크된 글은 기간이 지나도 삭제되지 않습니다.
- 예외 항목: 고정(pinned), DM, 좋아요를 받은 글, 북마크된 글(작성자 본인의 북마크), 투표(poll), 미디어 첨부 글.
- 자동 삭제 시 글과 함께 좋아요/부스트/북마크/투표/첨부 미디어가 정리되고, 연합 서버에 삭제가 전파됩니다.
- 서버가 바쁘면(CPU/DB 부하) 실행을 건너뜁니다.
